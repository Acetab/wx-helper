# 本群称呼与成员目录

机器人会自动读取群成员的微信昵称。普通成员不能通过 `/绑定` 自助建立人物档案；管理员确认成员身份后，用 `/绑定` 将其微信 ID 关联到人物档案。

绑定只影响当前群。同一个人在不同群可以关联到不同人物档案；未绑定的群使用从微信联系人缓存取得的微信昵称。`@` 气泡优先显示当前微信昵称，人物主名用于按人查询、知识检索和模型上下文。该功能不修改微信资料。

`members_config.json` 中的 `groups` 指定支持哪些群，成员列表可以为空。不同机器人账号、不同群的数据分别保存。实际绑定、已知身份和历史文本存放在 `.runtime/member_data.sqlite3`，重启保留。

框架先保存新消息，再分发给插件。默认原文长期保存；唯一维护者 `/清空` 仅重置对话上下文，不删除历史或成员绑定。空间人物与成员的关系需维护者 `/关联人物` 明确设置，同名不会自动合并。普通成员不能自助绑定或修改知识；管理员可用 `@群友`、`M编号`、微信昵称或 `wxid` 指定成员。

开发接口包括 `ctx.members.resolve(name, room)`、`display_name(wxid, room)`、`history(name, room)`、`today_snapshot(name, room)` 和 `today_group_snapshot(room)`。查询身份始终使用成员 ID，不能根据重名猜测是谁。
