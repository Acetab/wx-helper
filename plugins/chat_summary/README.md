# 按范围总结聊天

- `/总结 昵称 [N或今天]`：默认总结指定成员最近200条，可跨天。
- `/总结群聊 [N或今天]`：默认总结全群最近200条，可跨天。N为1—5000，今天表示当天全部有效文本。

称呼通过本群成员目录解析；微信昵称重名时可由管理员查看 `M编号` 并维护人物绑定。未绑定者的发言也会进入全群总结，成员 ID 不会被作为模型中的身份编号。

功能使用 `llm_config.json` 中的模型配置，需要启用 `chat_summary` 和 `history_enabled`；长期保存配置 `daily_clear: false`。以请求之前的消息为锚点，先过滤指令和机器人输出再计数，不查询未入库的微信旧历史。

重置上下文或连接结束会取消待发旧结果；正常跨天不取消。聊天文本会提交给自行配置的模型服务。完整说明见根目录《使用手册.md》。
