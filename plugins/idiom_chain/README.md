# 成语接龙

群里发送“成语接龙”开始游戏，机器人给出开场成语和当前接字。

一局只有一条接龙链，全群共享：任何人接对一轮就推进一次进度，换个人接着接会继承上一位的结果，而不是各自维护一条链。同一轮里先接对的答案生效，判定和发题期间到达的其他答案不重复计入。

只有恰好四个汉字、且首字等于当前接字的消息才当作答案；艾特机器人时说的成语同样算答案，艾特标签会被剥掉再判定。首字不对或长度不对的消息按普通群聊处理，机器人不回复，避免对日常聊天刷“接龙失败”。首字正确但不是成语时会提示失败并保留当前题。

进行中的进度写进成员库的 `room_states` 表（功能名 `idiom_chain`），重启、微信重连或插件重载后仍能接着上一局继续，并保留剩余的空闲时间。人格对话插件读同一份状态：答案由本插件判定，人格只据此聊天，不再自己编造进度。

规则为四字成语、末字接首字、同字衔接、同一条链不重复。基本格式和重复由本地校验，词义与下一词由配置的大模型判断。模型失败时保留当前题。

“合并接龙”保留为兼容命令，用来查看当前进度；“退出接龙”结束当前群的游戏。插件配置中的 `idle_seconds`（默认 1800 秒，范围 60–86400）控制空闲多久后自动结束这局。

`/help` 返回功能菜单。显示名字优先使用本群 `/绑定` 的称呼，其次使用微信名；不会复制其他群的绑定。该功能使用 `llm_config.json`，填写密钥后启用 `idiom_chain` 插件。

插件可单独启停或重载；未结束的局按空闲时间自动结束，不随重启丢失。
