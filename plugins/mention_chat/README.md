# 艾特机器人对话

从微信成员列表真正艾特机器人，再附上问题，即可触发回复。只键入看起来像 `@昵称` 的普通文字不会触发；艾特别人也不会触发。

上下文为发言者此前最多十条有效文字，以及全群此前最近五十条中去重后的发言，支持跨天；不混入其他群、控制指令和机器人输出。再检索相关长期知识，固定使用熟人损友语气，艾特目标始终为原发言者的真实ID。

本群有进行中的成语接龙时（进度来自成员库 `room_states` 表的 `idiom_chain` 状态）：恰好四个汉字、且首字等于当前接字的艾特消息完全交给接龙插件，本插件不回复；其余艾特消息会把接龙的真实进度（当前成语、接字、最近用过的词）作为 `room_game` 一起发给大模型，并要求它不要自己判定接龙、不要编造进度。没有进行中的接龙时不注入任何进度，也不提接龙。

显示名字优先使用该成员的本群绑定，未绑定时使用缓存中取得的微信名。功能需要成员记录、有效的模型配置和启用的 `mention_chat` 插件。

未绑定者会收到低频绑定提示。管理员重置上下文、修订相关知识或连接结束时会取消待发旧回复；正常跨天不取消。
