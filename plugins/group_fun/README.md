# 群聊趣味功能

围绕本群真实聊天提供语录竞猜、手动群报和群梗词典。没有定时推送，不监听普通聊天作答，也不生成虚构的“群友名言”。

在 `bot_config.json` 的 `plugins` 中加入并启用：

```json
"group_fun": {
  "enabled": true,
  "report_limit": 500
}
```

需要启用成员库聊天记录（`history_enabled: true`）并配置目标群。竞猜、原话查询和人工群梗维护不调用模型；群报（至少5条消息时）和未收录群梗的推测解释使用 `llm_config.json`。插件启动不强制读取模型密钥，缺少模型时仍可使用本地功能。模板默认关闭此插件。

## 这话谁说的

- `/谁说的` 或 `这话谁说的`：开始一局，共享同一题；进行中再次发送会重发当前题。
- `/猜 选项数字`：每人每题一次，先猜中的人 +1；原作者猜中或 `/谁说的 认领` 只揭晓，不得分。
- `/谁说的 提示`：每题一次，排除一个错误选项。
- `/谁说的 揭晓` 或 `/谁说的 跳过`：公布真实作者、时间、消息编号和前后相邻原话，之后用 `/谁说的 下一题` 继续。
- `/谁说的 状态`：查看当前题；`/谁说的 结束`：提前结束并显示本局猜中次数。
- `/谁说的 排除我`、`/谁说的 恢复我`：只设置实际消息发送者自己的出题偏好，按账号及群隔离。排除立即作用于当前题和后续题，不追溯删除聊天存档，不改变群报及普通原话查询权限。

出题从本群最近30天、最多2000条有效聊天中筛选 10–100 字、具有一定区分度的原话，避开重复内容、联系方式、链接、直接暴露作者姓名和转发/引用标记。需要至少3条合适原话及至少2位可区分的作者；够5题则出5题，不足5题时按实际数量。排除缺少可读称呼或称呼有歧义的作者，不要求提前 `/绑定`：联系人缓存中的微信名也能使用。

题目和选项由本地程序选择，模型不参与生成名言、作者或评分。猜错不扣分，没有强制倒计时，普通群消息中的数字不会被当成答案。每题最多记录100位错误作答者，达到后提示揭晓。揭晓的相邻原话最多前后各一条，跳过指令、机器人消息及已退出出题者的内容；相邻不代表一定在回复该句。

成功发送后才记录猜题次数、分数、提示及阶段；发送失败保留当前题，可重试。进度、选项和分数保存在本群状态中，重启后可以继续。原话被删除或作者退出出题后不再展示该题，允许跳到后面的可用题目。分数只在本局内统计，不写入长期成员画像。

## 今日群报

`/群报`、`/群报 今天` 或 `今日群报` 整理北京时间当天；`/群报 昨天` 整理昨天。只包含请求到达前已存入本群的记录，不夹带之后新收到的话。

有素材时展示“今天聊啥了”“发言摘录”“后续呢”“可能的新梗”；没素材的栏目不出现。消息不足5条时只展示少量原话，不调用模型。观点归纳附消息编号，摘录原话由本地记录还原，模型不能自行改写引用；模型给出不存在或不属于当前批次的来源编号时拒绝发送该份群报。

`report_limit` 默认500，范围50–2000。超过时仅取当天最近的指定条数，并在群报中说明；较长的单条消息仅把前600字交给模型，原文可查询。长记录分批整理，各栏目最多展示两项，并不保证覆盖每一个话题。没有最活跃/最嘴臭排名，不因为没看到后续就判某人失约。归纳和推测仍可能有误，应结合原话判断；不会自动把群报写入长期知识或群梗词典。

## 群梗词典

- `/群梗 关键词`：优先查本群人工词条；多个模糊匹配会返回编号列表，可用 `/群梗 #编号` 查看。
- `/群梗 随机`：从最近100条人工词条中随机翻一个。
- 尚未收录时检索本群含该关键词的原话，给出“当前存档最早可检索到的记录”，结合近期片段推测含义，明确标记“未确认”；没有记录就说明没找到，模型故障时直接展示出处，不编解释。
- `/群梗收录 名称 | 说明 | #原话编号[,#编号]`：建立本群词条；至少一条出处原文需包含名称。
- `/群梗补充 群梗编号 | 说明 | #原话编号`：任何本群成员都可追加说明，不覆盖正文。
- `/群梗修订 群梗编号 | 说明 | #原话编号`：仅原收录者或管理员（`owner_wxid` 指定的维护者）可修订正文，保留以前版本。

每次提交必须附1–5条本群真实原话，说明不超过200字。词典标出提交者及“群友收录/修订/补充”，不把某人的解释当作自动验证过的事实。展示最新正文和最近两条补充；历史修订保留在库内。原话删除后，仍保留群友提交的说明，但明确标记出处已不可完整核验。

“存档中最早找到”不等于真正的梗起源；其他软件、未开启记录时以及已删除的消息无法查到。新梗不自动永久绑定某位成员，也不自动追加进成员知识库。

## 核对出处

`/原话 #编号` 查看原文（最多展示前600字）及前后最多各一条相邻消息，支持逗号分隔最多5个编号。群梗编号和原话编号属于不同列表，输入时按对应命令使用。

查询始终使用当前机器人账号及当前群，不接受群ID参数。仅处理已配置群的文本消息；指令、机器人生成消息和私人会话不会进入出题及群报素材。长回复按原生接口的1023字节限制分段，发送前检查原始记录版本，清空或失效后取消待发内容。一次多段回复失败时，已发出的部分无法撤回，重试可能重复前几段。
